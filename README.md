# xonotic-webui

A web control panel for a **Xonotic dedicated server**.

Start, stop and watch your server from a browser, with a live console, a command
line and live status (map, gametype, players). Runs under a hardened systemd unit in
a Debian LXC or VM.

> Work in progress: the first release is being built. Install instructions will
> land here with it.

## Requirements

- Debian 12 or 13, amd64 (a Proxmox LXC works)
- Root for installation; the panel and the game server run as an unprivileged user
- About 1.2 GB download and a few GB of disk for the Xonotic 0.8.6 release
