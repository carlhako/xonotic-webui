# Screenshots

The panel at v0.6.0 on a Xonotic 0.8.6 server, captured at 1280×800 (shown at 1.5×;
`player-details.png` and `match-details.png` at 1280×1000). The matches are played by bots and two human players.

| file | shows |
| --- | --- |
| `dashboard-deathmatch.png` | the dashboard in a deathmatch: the match clock with its time and score limits, and the live scoreboard |
| `dashboard-team-deathmatch.png` | the same in team deathmatch: each team's total in its colour above its players |
| `players.png` | the Players section: the player history table, bots shown |
| `player-details.png` | a player's details: names, key, totals and the per-weapon table |
| `matches.png` | the Matches section: past matches newest first, with outcome, players, winner and the vs-bots tag |
| `match-details.png` | a team deathmatch's final scoreboard, grouped under each team's total |
| `maps-cards.png` | the Maps section: gametype, rotation and the installed maps as cards |
| `maps-files.png` | the Maps section's Files view: one row per map with its package, size, plays and frags |
| `settings.png` | the Settings section, Identity tab |
